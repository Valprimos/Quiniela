QUÉ CAMBIA
- Antes, ser admin de CUALQUIER pandilla (y cualquiera puede crear una) bastaba para corregir resultados, cerrar
  jornadas, tocar el pleno o el xG de todas las pandillas. Ahora esas rutas exigen ser administrador general.
- El resto del panel (jugadores, PIN, pronósticos, pendientes, temporada, copia, predicciones) no cambia.
- Los demás admins dejan de ver las herramientas globales; si llamaran a la API a mano, reciben un 403.
- Se comprueba en la base de datos que sigues siendo admin, así que quitar el rol surte efecto al momento.

CONFIGURACIÓN (recomendado, opcional)
- Por defecto, administrador general = admin de la pandilla más antigua (la primera que se creó).
- Para fijarlo: variable de entorno SUPERADMIN_PLAYER_IDS en Vercel con tu id de jugador (varios, separados por comas).
  Tu id: select id, name from players where name_key = 'tu nombre';   (SQL Editor de Supabase)
  Después, redeploy.
- Si al entrar no te aparecen Resultados, Pleno, Sincronización... es que tu pandilla no es la más antigua: define la variable.
